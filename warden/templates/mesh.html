Applying config

“Apply to host” writes {{ mesh.config_path or '/etc/wireguard/' ~ mesh.interface ~ '.conf' }} and runs wg-quick or wg syncconf. Warden must run as root or with CAP_NET_ADMIN to touch the interface.

Peer private keys stay in Warden's SQLite database so you can download a client file again later.

Route the whole LAN?

Set mesh.client_allowed_ips to your home subnets, for example 10.44.0.0/24, 192.168.1.0/24, to reach services without a public port.

Keys & trust

Each peer gets a private key, a preshared key, and a unique address. The hub config only ever contains public halves and the PSK.

Removing a peer deletes its keys from Warden. Apply again to drop the live session.
