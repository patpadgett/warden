How this stays safe

Warden stores only the public half of each passkey. The private key never leaves your device's secure enclave, and no password is ever transmitted.

Removing a passkey doesn't sign out browsers that are already signed in. Revoke sessions below if a device is lost. If you lose every key, run warden auth reset on the server.

Before you remove one

Always leave at least one working passkey on a device you can reach. Warden refuses to delete the last key, but it can't replace a lost phone.
