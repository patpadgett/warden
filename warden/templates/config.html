How saving works

Warden parses the whole file, validates every hostname, upstream, WebAuthn origin, and cookie scope, then writes atomically with mode 0600.

If validation fails, the file on disk is untouched and the editor keeps your draft.

Restart-only changes

Routes, protection, and headers apply immediately. Changes to server, tls, webauthn.rp_id, database, or mesh need a restart.

Before you edit

Keep a copy: cp warden.yaml warden.yaml.bak. Every route host must be the admin host, its parent domain, or be marked auth: false.
